
# GenAI Learning Lab

My Generative AI learning journey using Python, LangChain, Large Language Models (LLMs), embeddings, RAG, and AI agents.

## Goals

- Learn how LLMs work and interact with them using Python.
- Practice LangChain components.
- Understand embeddings and vector databases.
- Build Retrieval-Augmented Generation (RAG) applications.
- Learn AI agents and LangGraph.
- Develop practical Generative AI projects.

## Learning Roadmap

1. Python fundamentals and environment setup
2. LLMs and chat models
3. Embedding models and semantic similarity
4. Prompt templates and output parsers
5. Chains and LangChain Runnables
6. Document loaders and text splitters
7. Vector stores and retrievers
8. Retrieval-Augmented Generation (RAG)
9. Tools and AI agents
10. LangGraph and agent workflows
11. Evaluation and deployment

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Environment Variables

Create a local `.env` file for API keys when required.

Never commit `.env` or expose API keys publicly.
